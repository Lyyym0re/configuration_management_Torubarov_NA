# Эмулятор оболочки ОС

Консольный эмулятор оболочки для практической работы по конфигурационному
управлению. Реализация выполняется поэтапно; сейчас представлен этап 1 (REPL)
варианта 23.

## Этап 1: REPL

- приглашение содержит имя текущего пользователя, имя компьютера и `~`;
- парсер раскрывает переменные окружения (`$HOME`, `%USERPROFILE%` и другие);
- команды `ls` и `cd` являются заглушками и печатают имя и аргументы;
- `exit` завершает REPL;
- неизвестные команды и синтаксические ошибки разбора сообщаются пользователю.

## Запуск

Требуется Python 3.10 или новее. Запустите из корня проекта:

```text
python run.py
```

В Windows также можно запустить `run.bat`.

Демонстрационный BAT-файл запускает эмулятор, показывает команды этапа 1 и
ответы на них, затем оставляет REPL открытым для ручного ввода. После
завершения CLI нажмите клавишу, чтобы закрыть окно. BAT не вводит `exit`:

```text
tests/demo_stage1.bat
```

Для интерактивного завершения введите `exit`.
