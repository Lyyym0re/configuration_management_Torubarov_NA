# Эмулятор оболочки ОС

Консольный эмулятор оболочки для практической работы по конфигурационному
управлению. Реализация выполняется поэтапно; сейчас представлены этапы 1–5
варианта 23.

## Этап 1: REPL

- приглашение содержит имя текущего пользователя, имя компьютера и `~`;
- парсер раскрывает переменные окружения (`$HOME`, `%USERPROFILE%` и другие);
- на этапе 1 команды `ls` и `cd` были заглушками; с этапа 4 они работают
  с загруженной VFS;
- `exit` завершает REPL;
- неизвестные команды и синтаксические ошибки разбора сообщаются пользователю.

## Запуск

Требуется Python 3.10 или новее. Запустите из корня проекта:

```text
python run.py
```

В Windows также можно запустить `run.bat`.

Демонстрационный BAT-файл запускает эмулятор, показывает команды этапа 1 и
ответы на них, затем оставляет REPL открытым для ручного ввода. После
завершения CLI нажмите клавишу, чтобы закрыть окно. BAT не вводит `exit`:

```text
tests/demo_stage1.bat
```

Для интерактивного завершения введите `exit`.

## Этап 2: конфигурация

Эмулятор принимает два необязательных параметра командной строки:

- `--vfs PATH` — физический путь к VFS;
- `--script PATH` — путь к стартовому файлу команд.

При запуске выводятся оба значения. Если параметр не задан, выводится
`<не задан>`. Стартовый скрипт выполняется до
ручного REPL; при первой ошибке оставшиеся строки скрипта пропускаются, после
чего можно продолжать вводить команды вручную.

Примеры запуска:

```text
python run.py --vfs "C:\Users\user\Documents\vfs"
python run.py --script "C:\Users\user\Documents\startup.txt"
python run.py --vfs "C:\Users\user\Documents\vfs" --script startup.txt
```

BAT-сценарии этапа 2 находятся в `tests`:

- `demo_stage2_defaults.bat` — запуск без параметров;
- `demo_stage2_vfs.bat` — запуск с путём VFS;
- `demo_stage2_script.bat` — запуск со стартовым скриптом;
- `demo_stage2_all.bat` — запуск с обоими параметрами.

Запускайте по одному файлу. Каждый оставляет эмулятор открытым для ручного
ввода после демонстрации.

## Этап 3: виртуальная файловая система

Параметр `--vfs` указывает на каталог-источник. При старте все каталоги и
содержимое файлов читаются в неизменяемый снимок в памяти; файлы на диске не
изменяются. В диагностике показываются количество файлов, каталогов и общий
размер данных. Символические ссылки не поддерживаются.

BAT-сценарии создают три временных примера VFS: пустой каталог, каталог с
несколькими файлами и структуру с вложенностью не менее трёх уровней. Они
передают стартовый скрипт с `ls`, `cd` и ошибочным вводом. Скрипт прекращает
выполнение на первой ошибке, после чего REPL остаётся доступным для ручного
ввода. Начиная с этапа 4, `ls` и `cd` работают с содержимым VFS.

## Этап 4: основные команды

- `ls [путь]` показывает элементы каталога или имя файла;
- `cd [путь]` меняет текущий каталог VFS; без пути переходит в корень;
- `echo [текст]` выводит аргументы одной строкой;
- `tree [путь]` показывает дерево каталога.

Пути для `ls`, `cd` и `tree` могут быть относительными или начинаться с `/`.
Поддерживаются `.` и `..`, а также имена с пробелами в кавычках. Команды
работают со снимком в памяти, не изменяя каталог-источник. Текущий путь
показывается в приглашении. Для команд с VFS следует задать `--vfs`.

Запустите `tests/demo_stage4.bat` для примеров всех четырёх команд, вложенных
путей и остановки стартового скрипта после ошибки. Для отдельного примера
отсутствующего пути запустите `tests/demo_stage4_errors.bat`. После
демонстрации CLI остаётся открытой для ручного ввода. BAT не вводят `exit`.

## Этап 5: изменение VFS в памяти

- `rm путь` удаляет файл из текущего снимка VFS;
- `rm -r путь` удаляет каталог со всем содержимым;
- `vfs-load путь` загружает новый снимок из каталога на диске и переходит
  в его корень.

Удаление корня, текущего каталога или каталога над ним запрещено. Обычный
`rm` не удаляет каталоги. Если новый путь VFS неверен, прежний снимок и
текущий каталог сохраняются. Изменения `rm` не затрагивают файлы на диске.

`tests/demo_stage5.bat` показывает все доступные команды, удаление файла и
каталога, повторную загрузку VFS, реакцию на ошибку и сохранность исходных
файлов на диске. `tests/demo_stage5_rm_errors.bat` показывает ошибку при
удалении каталога без `-r`, а `tests/demo_stage5_load_error.bat` — ошибку
загрузки отсутствующего каталога. Каждый BAT оставляет CLI открытой для
ручного ввода. Команда `exit` в демонстрациях не используется.
