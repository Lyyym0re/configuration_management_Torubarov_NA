# Эмулятор оболочки ОС

Консольный эмулятор оболочки для практической работы по конфигурационному
управлению. Реализация выполняется поэтапно; сейчас представлены этапы 1 (REPL)
и 2 (конфигурация) варианта 23.

## Этап 1: REPL

- приглашение содержит имя текущего пользователя, имя компьютера и `~`;
- парсер раскрывает переменные окружения (`$HOME`, `%USERPROFILE%` и другие);
- команды `ls` и `cd` являются заглушками и печатают имя и аргументы;
- `exit` завершает REPL;
- неизвестные команды и синтаксические ошибки разбора сообщаются пользователю.

## Запуск

Требуется Python 3.10 или новее. Запустите из корня проекта:

```text
python run.py
```

В Windows также можно запустить `run.bat`.

Демонстрационный BAT-файл запускает эмулятор, показывает команды этапа 1 и
ответы на них, затем оставляет REPL открытым для ручного ввода. После
завершения CLI нажмите клавишу, чтобы закрыть окно. BAT не вводит `exit`:

```text
tests/demo_stage1.bat
```

Для интерактивного завершения введите `exit`.

## Этап 2: конфигурация

Эмулятор принимает два необязательных параметра командной строки:

- `--vfs PATH` — физический путь к VFS;
- `--script PATH` — путь к стартовому файлу команд.

При запуске выводятся оба значения. Если параметр не задан, выводится
`<не задан>`. На этом этапе путь VFS выводится как настройка; сама файловая
система будет подключена на следующем этапе. Стартовый скрипт выполняется до
ручного REPL; при первой ошибке оставшиеся строки скрипта пропускаются, после
чего можно продолжать вводить команды вручную.

Примеры запуска:

```text
python run.py --vfs "C:\Users\user\Documents\vfs"
python run.py --script "C:\Users\user\Documents\startup.txt"
python run.py --vfs "C:\Users\user\Documents\vfs" --script startup.txt
```

BAT-сценарии этапа 2 находятся в `tests`:

- `demo_stage2_defaults.bat` — запуск без параметров;
- `demo_stage2_vfs.bat` — запуск с путём VFS;
- `demo_stage2_script.bat` — запуск со стартовым скриптом;
- `demo_stage2_all.bat` — запуск с обоими параметрами.

Запускайте по одному файлу. Каждый оставляет эмулятор открытым для ручного
ввода после демонстрации.
